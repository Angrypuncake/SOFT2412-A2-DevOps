# VirtualScrollAccessSystem

## Instructions for Running the Program

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   ```

2. **Open the project**:
   - Navigate to the `SOFT2412-A2` directory and open the `VirtualScrollAccessSystem` folder using your preferred IDE.

3. **Ensure correct working directory**:
   - Make sure your working directory is set to `VirtualScrollAccessSystem` where the `build.gradle` file is located.

4. **Run the program**:
   - Option 1: In the terminal, run the following Gradle command:
     ```bash
     gradle clean build run
     ```
   - Option 2: In your IDE, navigate to the Gradle tasks, and under `Tasks -> application`, select `run`.

5. **Default Admin Credentials**:
   - The program comes with one preloaded admin user:
     - **Username**: `admin`
     - **Password**: `admin`
