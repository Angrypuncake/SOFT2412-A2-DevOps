## 📌 Project Overview

A full-stack web application developed under Agile methodology as part of the SOFT2412 Software Development Practices course at the University of Sydney.

This system was delivered across multiple sprints using DevOps principles, including:
- Continuous Integration via GitHub Actions  
- Semantic versioning via Git tags  
- Issue tracking and sprint planning using GitHub Projects  
- Modular, testable architecture with PR-based workflows

---

## 💻 Features

- Scroll tracking, analytics, and ID management for frontend components
- Modular React-based UI and Node.js backend
- Functional and integration testing
- GitHub Actions CI pipeline for linting, building, and testing
- Versioned releases (`v1.0.0` → `v3.0.0`)
