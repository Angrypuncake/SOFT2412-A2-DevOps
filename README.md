## 📦 Project Overview

Collaborative Agile software engineering project built over multiple sprints as part of SOFT2412 (Semester 2, 2024).  
Emphasis on **CI/CD**, **modular architecture**, and **cross-functional delivery**.

---

## 🚀 Key Features
- Full-stack web application with user-facing frontend and REST backend
- GitHub Actions CI for lint/test/build pipelines
- Sprint-based delivery using GitHub Projects + Issues
- Tag-based versioning: `v1.0.0`, `v2.0.0`, `v3.0.0`
- Scroll tracking + performance monitoring features (see `Elvis-ScrollStats`)
